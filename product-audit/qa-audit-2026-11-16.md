## Remaining work and limitations

**Not release ready.** This audit and remediation are incomplete. QA-01 and QA-02 remain: implement and test renewal reminders, grace with a banner, and invoices issued before payment. QA-06, QA-07, QA-09, QA-10, QA-12 and QA-13 remain: enforce minimum app version; default the CMS off with platform control; add real-data onboarding; translate guardian and public admissions with correct document language; add the requested deterministic mobile flow tests; and distinguish offline refresh from rejected credentials. SMS credits are not implemented. The endpoint/field contract, logging and full security review have not been exhaustively completed; successful integration tests do not establish complete coverage. The default console notification provider emitted test OTPs and addresses in local logs and needs production configuration and logging review.

Android release shrinking is configured but the release build was interrupted while Gradle was downloading dependencies; R8 and runtime keep rules are unverified. Direct Gradle release builds still fall back to debug signing without key.properties; the school build script refuses to do so. No signed release or Play submission was made. The iOS privacy declarations are preliminary and require validation against actual collection and Apple requirements. Flutter warns that the project has both Swift packages and CocoaPods integration; assess this before shipping. iOS signing, provisioning and store submission need authorised credentials. Legal documents are placeholders and must be approved and completed by counsel, with `NEXT_PUBLIC_COMPANY_NAME` configured. Real provider credentials, production configuration, and operational verification remain external work.
